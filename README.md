# ktblog

Personal blog for learning frontend, backend, databases, and deployment.

## Project Structure

```text
.
├── web/      # Frontend: Astro + TypeScript
├── api/      # Backend: Go HTTP API
├── deploy/   # Deployment config (e.g. Docker, CI)
└── docs/     # Roadmap, notes, architecture decisions
```

## Tech Stack

- **Frontend:** Astro + TypeScript, Tailwind CSS, React islands
- **Backend:** Go (Gin)
- **Database:** PostgreSQL
- **Deployment:** Cloudflare Pages (web), VPS + Caddy (api), Docker Compose + GitHub Actions
